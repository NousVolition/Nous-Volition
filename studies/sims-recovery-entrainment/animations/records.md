# Institutional records and carried memory

Download the repository and open the HTML files in a browser. GitHub's file view shows their source. The standalone pages contain their styling and runtime; no account or network connection is needed for playback.

## Basis

These are deterministic causal demonstrations with explicit assumed rules. The user-provided passages about institutional classification motivated the question; they do not supply these equations, parameter values or numerical predictions. This is not a fitted or validated model of people, and it does not reproduce a source equation. Familiar and Explore name two abstract routes, not good and bad behaviour.

## Shared model

Two otherwise identical SIMS, A and B, start with the same internal expectation `m = 0.5`. Their initial institutional records differ: `r_A = 0`, `r_B = 1`. The institution offers access `u = 1 - 0.75 r`, so an unflagged record gives 100% and a flagged record 25%. These percentages are model inputs, not measured access rates.

During a visit, `dm/dt = (u - m)/8`. Between visits, memory is retained unchanged. A SIM chooses Explore if `m >= 0.6`, otherwise Familiar. Identity never enters these rules.

Six paired visits depart at model times 0, 12, 24, 36, 48 and 60. Arrival is two units after departure; learning lasts three units. Visits are scheduled externally, not generated by an autonomous oscillator. Before the intervention at time 24, A has expectation 0.763816724 and B 0.368091638. Their difference arose from prior unequal treatment despite equal starting memories and the same response rule.

## Record and memory interventions

At time 24, compare four cases: keep both; erase only the records (`r_A = r_B = 0`); reset only internal memory (`m_A = m_B = 0.5`); or reset both. Intervention preserves positions and the displayed historical itinerary. Resetting memory changes the current expectation, not past events.

Erasing records restores equal offered access immediately, but B first still chooses Familiar. With continued equal access, its next choice becomes Explore. Resetting memory alone leaves differential records in place, which rebuild the difference. Resetting both aligns later treatment and memory. In this experiment records remain fixed after the intervention.

## Recreated records

The second animation begins at time 24 just after record erasure, retaining the same memories in both comparison cases. It adds one optional rule applied equally to A and B: a newly observed Familiar route writes a flag; Explore writes no flag. The classifier uses only the current route observation, never an old record, the SIM's identity or direct access to its memory.

The first post-erasure visit runs from time 26 to 29. B's expectation rises to about 0.57, below the route threshold. Its new Familiar choice is observed at time 31 and reviewed at time 32. With reclassification enabled, this recreates B's flag. The record change affects the next visit, whose learning begins at time 38; it does not retroactively change the completed visit. The two cases' memories remain identical through time 38.

On later visits, the flag reduces access, which sustains the expectation associated with Familiar, which in turn sustains the flag. With reclassification disabled, the same initial observation writes no record; access stays equal, and B chooses Explore at time 43. At time 72, B's expectation is about 0.35249 with reclassification and 0.85900 without it.

The feedback result depends on the selected classifier, access penalty, learning rate and route threshold. It illustrates how erasing a record can fail to remove the process that produces it; it does not establish that every institution or person follows this loop.

## Verification

Run from this directory using Node.js, with no additional packages:

```sh
node check_records.cjs
```

The runner checks shared starting conditions/history, isolated resets, exact memory preservation, identity permutation symmetry, equal-record controls, chronological observation and record writing, absence of retroactive treatment, and agreement between closed-form learning and an independent RK4 calculation. Maximum absolute RK4 difference was below `4.0e-15` in these cases. The disabled-reclassification case exactly reproduces the first experiment's record-erasure case.

Offline DOM/control checks execute the scripts against a small mock document: play/pause, checkpoint pauses, seeking, replay, state restoration, reduced motion and optional host failures. Static export checks confirm the embedded fragment matches its source, JavaScript parses and external scripts are absent. These checks are not visual browser inspection; browser rendering and layout of these two additions remain unverified.

Saved results: [record/memory checks](checks/records-memory.json), [feedback checks](checks/records-recreated.json), and [export checks](checks/record-exports.json). Running checks rewrites these verification records; the study's hash manifest describes the published versions.
