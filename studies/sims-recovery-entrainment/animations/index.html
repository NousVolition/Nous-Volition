What changes within, and what changes with place?

Seven animations follow that question from a change in position to a repeated cycle of experience, stored memory, and choice. Download the repository and open this guide locally to play them. GitHub displays HTML source.

  1. Opposite rotations without an equilibrium between
    The inner orbit rotates clockwise, the outer orbit counterclockwise. At the turning circle, angular speed is zero but outward motion continues. Use At reversal to inspect it.
  2. Changed position versus changed internal state
    One SIM moves; the other stays in place but receives an internal bias change. Their early responses match by construction. Returning the moving SIM separates those explanations.
  3. A journey changes what the SIM carries home
    Both make the same trip. One stores a slow exposure trace, visible as its inner ring. Compare retained and fading traces. Both still have a fast response lag; the control disables the additional storage mechanism.
  4. Carried memory changes the next destination
    Both reach the same fork. Under the assumed rule, a trace above 0.80 selects Explore, otherwise Familiar. A longer wait can let fading memory change that decision.
  5. The destination changes memory again
    Three further trips close the feedback cycle. In Balancing mode, Explore reduces the trace and Familiar rebuilds it; choices become Explore → Familiar → Explore. In Reinforcing mode, Explore strengthens the trace and the SIM chooses it three times. The storage-disabled comparison always chooses Familiar. Use Next choice to inspect each fork.
  6. Same SIMS, different institutional records
    Initially identical A and B receive different access because their records differ. At a shared checkpoint, compare keeping both states, erasing records, resetting memory, and resetting both.
  7. When the institution recreates an erased record
    Both cases begin just after record erasure, with memory retained. One institution writes a new flag from a newly observed Familiar choice; the other does not reclassify. Use Play to first rewrite, then Continue feedback.

Assumptions in the first five animations

The SIM identity A stays fixed. Position and stored state are separate variables. The scalar trace summarizes a stored effect; it is not a record of detailed memories or learned weights. All animations are deterministic mechanism examples. They do not establish preferences in people, a brain model, or a physical law. The six water-related group names elsewhere in the study remain a social analogy.

The first journey is imposed: departure over times 2–4, a visit until time 7, and return over 7–9. For the response examples, dx/dt = u + m − x, where u is the current context. The internal-bias comparison instead supplies a controlled bias. The trace grows during the first visit according to dm/dt = 0.6 p(2 − m) − (1 − p)m/τ, with exposure p between 0 and 1. Retained mode omits the decay term.

For the repeated cycle, choices occur at times 14, 24, and 34. Each chosen destination is reached two time units later and visited for three time units, then the SIM returns home. During a destination visit, dm/dt = 0.6(target − m). Balancing targets are Explore = 0 and Familiar = 2; Reinforcing reverses those targets. Between visits, the trace either stays constant or decays with time scale 12. Choice is evaluated once at each fork from the current trace; later updates affect the next fork. Paths are computed from that rule, not stored as a preset sequence.

In the orbit example, let q = x² + y², g = (q − 1)(4 − q), and w = q − 2.5. The smooth field is dx/dt = gx − wy, dy/dt = wx + gy. The reversal radius is √2.5; there dr/dt = (9/4)r > 0. The origin is the only equilibrium and lies inside the inner orbit, not between the two orbits.

Institutional records and feedback

The two record experiments use a separate stated model: a flag changes offered access, experience updates an internal expectation, and that expectation affects a route choice. The second experiment adds a classifier which treats Familiar as grounds for a flag. That interpretation is an assumed institutional rule, not a judgment that the route is objectively wrong. The same rule applies to A and B; their names have no causal role.

Checks for the first five animations

The original five animations were executed and inspected. The four position/memory models have saved numerical and browser-check records in checks. Checks include independent analytic solutions, half-step agreement, storage-disabled controls, playback and scrubbing, controls, saved-state restoration where applicable, and narrow-screen layouts. They are verification of these examples, not new population replications. The orbit animation was also checked at reversal and during playback; this package includes a new export playback check.

Portable numerical checks: node check_models.cjs from this directory, using Node.js without additional packages. Editable animation fragments are in source. The standalone pages embed the styling and runtime needed for local playback; no account or live service is required. The manifest records file hashes. Previously published ensemble results remain separate.

Optional browser verification: install Playwright and its Chromium browser, then run node check_browser.cjs. Set SIMS_BROWSER_EXECUTABLE to use an installed Chromium browser instead. This repeats export playback, layout, local-link, error, and zero-network-request checks. It writes records into checks; historical check records and their manifest hashes describe the delivered files.
