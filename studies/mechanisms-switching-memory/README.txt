MECHANISMS, SWITCHING AND MEMORY

Open report.html. It embeds both figures and works offline. This directory
contains the complete switching supplement in Streams and Rocks. Numerical
outputs are unchanged from the completed local study. No laboratory work,
exposures or external account is needed.

REPRODUCE
Python 3.12 recommended. In this folder:
  python -m venv .venv
  Windows: .venv\Scripts\activate
  macOS/Linux: source .venv/bin/activate
  python -m pip install -r requirements.txt
  python run_study.py

The runner first executes the unit tests, then deterministic calculations and
168 seeded finite-count simulations, and writes figures, report and archive.
Run the tests alone with: python -m unittest -v test_models.py
Do not redirect stdout into this folder while building the archive. Use an
external temporary log path if desired. No network is used by the scripts.

FILES
models.py: equations, exact/reference identities, numerical methods
test_models.py: analytic limits, force gradient, conservation, positivity,
  numerical refinement, controls and seeded repeatability
run_study.py: complete reproduction, figures, report and packaging
results.json: units, inputs, outcomes, roots, error values and individual seeds
trajectories.npz: plotted deterministic trajectories; spring state stores y,
  dimensionless heat and parameter work, with time converted to seconds
mechanisms.png / .svg: physical/chemical mechanisms and controls
verification.png / .svg: noise, refinement and feedback-strength sensitivity
references.json: sources and explicit data provenance
test_log.txt: actual verification output
manifest.json: SHA256 hashes for packaged files
switching_tests.zip: optional archive generated by rerunning; not committed
  because all source, results and raw arrays are stored individually here

ASSUMPTIONS AND UNITS
Spring: a=.01 m, L0=.02 m, k=1 N/m, gamma=2 N s/m, mass=.01 kg.
The implemented equation is overdamped; tau=k*t/gamma, y=x/a,
b=mg*sin(theta)/(k*a). Ideal spring supports compression. No Brownian forcing.
Each pulse run begins at the left equilibrium at zero tilt. Strong-drag
approximation is selected by mk/gamma^2=.0025; inertia is not simulated.
The spring's imposed changing tilt contributes explicit parameter work.

Chemical: active fraction p; total protein 1 micromolar. ASSUMED rates v=2/s,
d=1/s, pulse stimulus=.5/s, Hill K=.3 (fraction), n=4. These rates are not
calibrated to any organism or substance in the main study. All rates are
effective, not elementary mass-action collision constants. Hill kinetics is
not evidence of a particular enzyme identity or stoichiometric cooperativity.
Protein conversion and ATP/phosphate accounting are checked. Complete
atom/charge/chemical-free-energy/heat closure is not claimed.

Main chemical pulses assume replenished ATP. Finite-fuel comparison starts
at the high equilibrium with 2 micromolar ATP and an extra assumed factor
ATP/(.1 micromolar+ATP). No ATP recycling, buffered water/protons.
Stochastic runs use exact Gillespie sampling of the chosen phenomenological
birth/death process, 24 seeds per condition, N=100/1000, 20 s after pulse.
N changes the modeled volume at fixed concentration. At 1 micromolar, volumes
are N/(6.02214076e23 * 1e-6) litres. This tests only intrinsic count noise.
Reported intervals measure finite-trial sampling, not parameter uncertainty.

The supplied refuge/outbreak crop lacks its rate equation. We interpret its
folded stability geometry but do not claim a population-model reproduction.
The bead equilibrium is the supplied textbook equation. Chemical feedback is
our explicit bounded hypothesis, inspired by the screenshot and primary
literature. It is NOT an exact replication of Xiong and Ferrell (2003).
Nothing here introduces reactions or feedback into the existing CO/water,
VOC/fog, H2O2 or charged-droplet calculations. This is no new fluid law.
