# Reference, wording and time: frozen analysis specification

Fixed after source/schema inspection and before fitting field parameters or computing outcome summaries. This is an exploratory analysis of a newly acquired public source, not externally preregistered research. Source: OneCommon AAAI2020 annotations, pinned repository commit and file hashes in source_manifest.json. Do not describe annotated reference as all of intended meaning.

## Measurements and descriptive tests

Use original dialogue message times and speaker order; align annotation text lines to original messages only if line counts and speaker sequence agree. Annotation wording includes the authors' spelling/grammar normalization. Referring-expression labels are retrospective human interpretations, not original-speaker self-reports; annotators had full dialogue/context access. Report this future-context limitation.

Retain non-generic expressions with nonempty, identifiable, non-ambiguous aggregate referents and at least three MT-worker judgements. Compute pairwise exact referent-set agreement among MT workers, counting unidentifiable judgements as disagreements. Exclude dialogues with an admin adjudicator from primary analysis so agreement and the aggregate labels are not silently mixed with manually overridden labels. Keep all exclusion counts. Only successful dialogues were annotated by the original project; no success/failure or penalty comparison is possible in this annotated subset.

Within each speaker/dialogue, pair each expression with the most recent earlier expression referring to the exact same object set in a different utterance. Compare changed versus unchanged normalized wording and report agreement changes. Same referent does not imply identical full meaning, social force or truth conditions; later context differs. Separately count identical normalized wording used for different referents. Compare consecutive cross-speaker eligible utterances using canonical object IDs (strip agent prefix) to describe reference overlap through interaction; do not equate this with copying or causation. Bootstrap by dialogue, 2,000 resamples, seed 20261023.

## Full coupled field test

Preserve corpus P229–230, P517–519 and P545–550 exactly as the continuum equations, using the existing checked numerical solver's algebra. The added observation hypothesis H_ref is explicit: S(x,t) is a kernel density of the distinct objects referred to by one speaker's retained expressions in an utterance (one unit integral per object); U(t) is mean human referent-interpretation agreement for that utterance. U is a proposed recoverability utility proxy, not the corpus's definition of personal utility or Sens. Actual expression text is used in the wording audit; the PDE is given annotated states and agreement, not an unimplemented natural-language decoder.

Positions are from that speaker's actual view, scaled by 430 coordinate units. Keep each speaker in their own coordinate frame; perspectives can differ. Smooth periodic kernel: K proportional to exp((cos(2*pi*(x-x0))+cos(2*pi*(y-y0))-2)/(2*pi*h)^2), discrete spatial integral one, h=.12. These are explicit observation kernels on an assumed periodic unit square, not measured human fluid density. Use the first three eligible utterances of each speaker as a two-interval episode; retain episodes with strictly positive measured intervals <=120 seconds each. Time unit is one minute. Initial S is the first annotated field; u0=0 and A0=0 are explicit unmeasured initial conditions. Source position is the first referent centroid, fixed throughout the episode. No assimilation/reset at the middle observation. Inputs are held at the latest previously observed agreement. Outcomes are the two subsequent annotated fields. Gold annotations are retrospective oracle inputs, so this is an offline conditional prediction test, not a deployable prospective forecast.

Assign whole scenario clusters by SHA256('reference-field-v1|' + scenario id), first 70% training, remaining evaluation. A scenario reused in multiple dialogues stays together. Within each split choose one eligible speaker episode per scenario in case-hash order, then the first 64 training scenarios and first 64 evaluation scenarios by hash. This is a tractable pilot, not all-corpus field validation; descriptive statistics use all eligible records. No selection based on errors or changes of referents.

Fit Ubaseline as the mean initial agreement over the 64 training episodes. Fix gamma=rho=1; fit real kappa by equal-episode least squares on the two exact integrated-mass predictions, using actual elapsed time. Kappa's sign is not specified by the corpus; retain it and also report the nonnegative-fit sensitivity. Only kappa*gamma is identifiable from mass. Spatial parameters are selected using only training field MSE on a fixed grid: D in {0,.001,.01}, sigma in {.0001,.001,.01}; nu=.02, Gamma=1, e=(1,0), mu0=rho*nu. Primary law: sharp. These parameter ranges and all geometric assumptions are exploratory, not measured human constants. Fit the best force-off D separately as a control. Compare fixed initial-field persistence, last observed field, and force-off with the selected coupled model. Select by training MSE only, ties by list order. Test once on the 64 evaluation episodes; report all cases and paired scenario-bootstrap differences.

Use a batched implementation numerically equivalent to the checked single-case solver, 16² grid, RK4 with max step .005 minute, shorter step where required by the diffusion cap. In each episode the two intervals may have different measured durations. Preserve the velocity zero mode and original signed-tanh tail. Do not replace force by drag, add forgetting or clip S. Check original signed tanh and smooth exact-off at the selected parameters as sensitivities, not refitted winners. Compare source-off (kappa=0). Refine the first four evaluation case hashes to 32² and halve the 16² time step; report errors and whether they affect interpretation. If numerical instability occurs, reduce time step without changing fitted candidates and disclose it.

## Verification and limits

Check batched versus original single-case RHS/trajectory, discrete divergence, pressure, stress, exact mass integral, energy work/dissipation and source normalization. Preserve the original corpus source hash and solver hash. The new data measure spatial referents, interpretations, expression and time, but not social velocity, pressure, personal utility, boundary fluxes or moderation. Even a good conditional fit would not establish literal human fluid dynamics. Do not claim causal wording effects, equivalence of all meaning, penalty memory, helpful/rival doubles, or a new Navier–Stokes law. Publish code and derived numeric records only, with source provenance; no raw transcripts, worker IDs or original corpus attachment.
