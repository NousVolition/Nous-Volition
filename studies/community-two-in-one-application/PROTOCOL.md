Frozen before inspecting response values in the NEMAR on007216 dataset. The codebook and file listing have been inspected. This is a timestamped local analysis plan, not an externally registered preregistration.

## Scope and definitions

The exact corpus momentum, pressure, incompressibility, signed S transport, accumulated A input and stress equations remain the dynamics. An observation/initialization rule is a separately declared application assumption, never attributed to the corpus. No reduced time-series predictor will replace the PDE. Controls may disable a mechanism while retaining the numerical architecture. The source corpus, original solver and this protocol receive hashes.

Each person has a separate state and ordered history record. No person's observations become another person's history. Unknown pre-study events are unknown. A(0)=0 remains anchored to a model origin earlier than an uncertain observation-start state. A known first observation is not evidence that life began at that observation.

Smoke is inward putting-forward and Clay is inward receiving, within one person. Wind, Fog, Mist and Water describe the moving idea. Water is perceived balance. Following the author's clarification, D2O denotes the sensitivity question of a small compositional change having a large consequence; it is not an automatic harm label or a chemical toxicity predictor. No survey item will be renamed as a direct measurement of one of these concepts unless its wording supports that claim. Untested forms remain explicitly unmeasured.

## Split and data discipline

Sort participant IDs by SHA256 of the literal string 'two-in-one-2026-v1:'+ID. The first eight are reserved evaluation participants; all others are development. No response values from reserved participants are inspected for choosing the model. Participant/session/run order remains separate. Do not simulate an unrecorded interval between scan runs or days as if its input or duration were known.

Within each run, use its first half of valid consecutive probes as observed calibration/history and forecast the second half without feeding later target ratings into state updates. Source schema and missingness may be audited across all files without viewing reserved response distributions. All departures from this plan must be recorded before interpreting results.

## Observable and model specification

The primary candidate observable is the participant's reported freedom of thought movement (mvmt). Secondary context descriptors are the actual items in the source dictionary, with anchor directions retained. Reports are not continuous movement trajectories, direct meaning measurements, or separate Smoke/Clay states. Any measurement operator and initialization must be frozen in MODEL_SPEC.md before loading reserved responses. If these cannot be defensibly specified, report that failure rather than invent a successful empirical test.

Calibration uses only early observations and development participants. Parameter selection uses later observations of development participants. The frozen selected specification is then applied to the reserved participants, using only their early history for individual initialization. Report participant-balanced errors and paired uncertainty by participant; probes are not independent people. All prediction scales and transformations must be explicit. No clipping of out-of-range predictions to improve scores.

## Checks and claims

Check the PDE implementation against the original solver, exact accumulated-source mass accounting, incompressibility and an analytic benchmark. Refine space and time. Check that changing a target response cannot change its prediction; history windows do not cross people/runs; missingness is not a zero score. Mechanism controls include no force, no accumulated source, and a declared history control. Include sensitivity to initial state uncertainty and small perturbations; a numerical threshold crossing is not proof of help or harm.

A fit of reported movement would test this explicit observation mapping, not all the author's constructs. Full two-in-one validation requires observations that distinguish the inward roles, content/history, forms and consequences. Do not equate confidence with memory clarity, affect with perceived balance, temporal focus with felt time, or verbalness with the inward speaker alone.
