1. **Order test.** Scale valence and temporal reference from [-1,1] to [0,1], leave self-relevance on [0,1]. Calculate each participant's mean squared Euclidean displacement over adjacent valid responses within each chain, excluding all chain boundaries. Compare with 999 independent within-person, within-chain permutations of complete response vectors (missing positions fixed). Test smaller displacement, group statistic is equal-person mean, Monte Carlo p=(1+count(null<=observed))/1000. Report each coordinate too, descriptively. A rejection indicates order dependence under this exchangeability null; task design, semantic association and response style remain alternatives to a causal memory effect.
